● Claude UI

Configuration au premier lancement

1. Autoriser l’app Permission pour piloter Termux.
2. Dans Termux (une seule fois) Installe Termux depuis F-Droid (pas le Play Store). Copie cette commande, ouvre Termux, colle-la, puis valide. mkdir -p ~/.termux && echo "allow-external-apps=true" >> ~/.termux/termux.properties && termux-reload-settings
3. Installer Claude UI + OmniRoute Ouvre une session Termux qui installe tout (quelques minutes). Reviens ensuite dans l’app.

En attente du serveur local…
L’écran de configuration (clé OmniRoute, dossier, modèle) s’ouvrira automatiquement.
